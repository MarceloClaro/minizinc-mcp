# MiniZinc Constraint Solver MCP Server

A Model Context Protocol (MCP) server that provides constraint solving capabilities using MiniZinc. This server exposes a single powerful tool for solving constraint satisfaction and optimization problems.

## Features

The server provides one core tool:

- **solve_constraint** - General purpose constraint solver that accepts any MiniZinc model with optional data parameters, solver selection, and timeout configuration

## Usage Options

### Option 1: Use Hosted Version (Recommended)

The easiest way to get started is using our free hosted version at:
```
https://minizinc-mcp.up.railway.app/sse
```

### Option 2: Self-Host with Docker

Build and run locally:
```bash
git clone <repository-url>
cd ccake
docker build -t minizinc-mcp .
docker run -p 8000:8000 minizinc-mcp
```

### Option 3: Local Development

Prerequisites:
- Python 3.11+
- MiniZinc 2.8+ (install from https://www.minizinc.org/software.html)

```bash
git clone https://github.com/r33drichards/minizinc-mcp
cd minizinc-mcp
pip install -r requirements.txt
python main.py
```

*"Find the optimal solution to a knapsack problem with items having weights [2,3,4,5] and values [3,4,5,6] and capacity 7"*

*"Solve this custom constraint: I need two variables x and y between 1 and 10 where x + y = 15 and x < y"*

## Response Format

The solve_constraint tool returns a `SolveResult` object containing:
- `solutions`: List of solutions found
- `status`: Solving status (SATISFIED, OPTIMAL, UNSATISFIABLE, etc.)
- `solve_time`: Time taken to solve in seconds
- `num_solutions`: Number of solutions found
- `error`: Error message if solving failed

Each solution contains:
- `variables`: Dictionary of variable names to values
- `objective`: Objective value for optimization problems
- `is_optimal`: Whether the solution is optimal

## QCAF Quantum Admissibility Extension

This fork adds QCAF (Quantum Constraint Admissibility Framework), a bounded constraint-analysis layer for reproducible observations generated by PennyLane, Qiskit, Cirq, or other quantum frameworks.

New MCP tools:

- `quantum_admissibility`: selects an observation satisfying all declared thresholds and can optimize target probability, BER, or fidelity.
- `generate_qcaf_colab_notebook`: generates a portable nbformat-4 Google Colab notebook containing the QCAF request and reproducibility boundary.

The generic `solve_constraint` tool remains available for backward compatibility.

### Install from Git

```bash
pip install "git+https://github.com/MarceloClaro/minizinc-mcp.git"
```

MiniZinc must also be installed on the host. For Debian/Ubuntu:

```bash
sudo apt-get update
sudo apt-get install -y minizinc
```

Run as a local stdio MCP server:

```bash
minizinc-qcaf-mcp
```

Run as SSE:

```bash
minizinc-qcaf-mcp-sse
```

### QCAF input

A QCAF observation records target-state probability, BER, noise probability, circuit depth, shots, optional fidelity, and provenance such as framework, backend, seed, circuit hash, parameters, and metadata. See `examples/qcaf_request.json`.

Result semantics:

- `ADMISSIBLE`: at least one supplied observation satisfies every threshold.
- `INADMISSIBLE`: no supplied observation satisfies the thresholds.
- `UNRESOLVED`: the bounded calculation did not yield a trustworthy terminal witness.
- `ERROR`: preparation or solver execution failed.

Important: `INADMISSIBLE` applies only to the finite supplied observation set; it is not a proof of global impossibility.

### Colab workflow

Generate a notebook with the MCP tool `generate_qcaf_colab_notebook`, then either materialize it through the companion `MarceloClaro/colab-mcp` bridge or generate/execute it with `MarceloClaro/google-colab-cli`.
